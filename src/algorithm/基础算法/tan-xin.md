---
title: 贪心
---

贪心算法是 CSP-J/S 中非常常见的一类思想：在**每一步**都做出当前看起来**最优**的选择，并期望通过**局部最优**的累积得到**全局最优**。它的代码通常很短，但难点在于证明“**局部最优能推出全局最优**”，以及识别什么问题不能用贪心。  

## 贪心解决什么问题

### 1.核心特征 ： 

贪心适用于满足以下条件的问题：  

- 最优子结构：问题的最优解包含子问题的最优解。  
  <span style="color:#A9A9A9">详细解释：一个问题的最优解，可以由它的子问题的最优解组合得到。换句话说：“大问题的最优答案，是从小问题的最优答案拼出来的。”形式化地说，如果问题 P 可以分解为子问题 P₁、P₂、…，那么 P 的最优解一定包含 P₁、P₂、… 的最优解，而不是次优解。</span>  

- 贪心选择性质：每一步的局部最优选择，能导向全局最优解，且不需要回溯。  
  <span style="color:#A9A9A9">回溯 = 发现当前选择走不通或不是最优时，退回到上一步，撤销这个选择，换另一个选择重新尝试。贪心在每一步做出选择后，就永久确定这个选择，继续往下走，永远不会退回来撤销它、换别的选择。 </span>  

- 无后效性：某个状态一旦确定，它之后的发展只与当前状态有关，与到达这个状态的路径（历史）无关。  
  <span style="color:#A9A9A9">换句话说：“未来只取决于现在，不取决于过去怎么来的。”形式化地说，如果当前状态是 S，那么从 S 出发能得到的后续结果，完全由 S 本身决定，不需要知道“我是从哪条路走到 S 的”。 </span>   

通俗地说：“只看眼前，选了就不后悔”，并且这种短视策略恰好是正确的。  

### 2.与DP的区别

**关键区别**：贪心是“一条路走到黑”，DP 是“把所有路都考虑一遍”。如果贪心选择性质不成立，贪心就会出错，必须改用 DP。  

### 3. 贪心的典型步骤

1. **明确目标**：要求最大还是最小？  
2. **找贪心策略**：按什么规则排序？每次选哪个？  
3. **验证正确性**：尝试举反例，或用交换论证证明。  
4. **实现**：通常先排序，再一次扫描做出选择。  



## 经典贪心模型

### 1.区间调度问题

**问题**：有 n 个区间 [li, ri]，选择尽可能多的互不重叠的区间。  

**贪心策略**：**按右端点升序排序**，每次选择右端点最早结束且与已选区间不重叠的区间。  

**为什么按右端点？** 右端点越早，留给后面区间的空间越大。按左端点排序会出错（反例：[1,10], [2,3], [4,5]）。  



### 2.区间覆盖问题

**问题**：用最少的区间覆盖 [1, m]。  

贪心排序规则是：**按左端点升序排序**，**在左端点相同的条件下，右端点降序。**  在当前已覆盖的右端点范围内，选择能延伸到最远的区间。  



### 3. 排队接水问题

**问题**：n 个人接水，第 i 人需要 ti 时间，求所有人等待时间之和最小。  

**贪心策略**：**按接水时间升序排序**，时间短的先接。  

**证明（交换论证）**：若相邻两人 a 在 b 前，a 耗时 ta > tb，交换后总等待时间减少，所以短时间在前更优。  



### 4. 货仓选址问题

**问题**：数轴上 n 个点，选一个点使所有点到它的距离之和最小。  

**贪心策略**：选**中位数**。排序后取 `a[n/2]`。  



### 5. 合并果子（哈夫曼思想）

**问题**：n 堆果子，每次合并两堆，代价为两堆之和，求最小总代价。  

**贪心策略**：**每次取最小的两堆合并**，用优先队列维护。  



### 6. 田忌赛马

**问题**：双方各有 n 匹马，，每匹马有一个速度vi，可以决定比较顺序，每匹马只能比一次，比较过程中：速度快的得200，速度慢的扣200，平局钱不变。求田忌最多能赢多少。（原题：洛谷P1650 田忌赛马）  

1.能平局则平局对吗？反例：双方都是1,2,3。如果按能平则平，那么最后得到的钱是0，但是正确方法是田1->齐3用最弱消耗掉对方最强的输一局，再用强的赢两局，得到200  

2.能赢则赢对吗？反例：田：1,3,5。齐：3,4,6。这个策略就是错的。  

关键洞察：**田忌最快的马是最宝贵的资源**，它应该用来赢对方最强的马，而不是浪费在平局或消耗上。田忌最慢的马是最不值钱的资源，适合用来牺牲、消耗对方。  

我们用 `t_fast`、`t_slow` 表示田忌最快/最慢的马，`q_fast`、`q_slow` 表示齐王最快/最慢的马。  

#### 情况 1：`t_fast > q_fast`

**田忌最快的马能赢齐王最快的马。**  

**决策：直接比，赢。**  

**为什么？** 齐王最快的马是对方最强的主力，田忌用最快的马稳稳赢下它，既拿到 200 银币，又消灭了对方最大的威胁。这是最划算的交易，没有任何理由不这么做。如果这时候还拿慢马去消耗，反而浪费了 `t_fast` 的胜利价值。  

#### 情况 2：`t_fast < q_fast`

**田忌最快的马都打不过齐王最快的马。 ** 

**决策：用田忌最慢的马去消耗齐王最快的马，输掉这一场。**  

**为什么？** 既然 `t_fast` 都赢不了 `q_fast`，那田忌**任何一匹马都赢不了齐王最快的马**。与其让 `t_fast` 去送死（浪费强马），不如派最没用的 `t_slow` 去牺牲，把 `q_fast` 消耗掉。这样田忌的强马都保留下来，后面还能赢齐王剩下的马。**输一场，但保存了主力。 ** 

#### 情况 3：`t_fast == q_fast`

**双方最快的马速度相同。** 这是最复杂的情况，不能简单打平，要再分。  

##### 3a. 先看 `t_slow > q_slow`  

**田忌最慢的马能赢齐王最慢的马。 ** 

**决策：用 `t_slow` 对 `q_slow`，赢。 ** 

**为什么？** 既然最慢的马都能赢对方最慢的马，那这是一场**白赚的胜利**，先拿下。此时不动 `t_fast`，保留它应对后面的局面。如果急着拿 `t_fast` 去和 `q_fast` 打平，就浪费了 `t_slow` 能赢的机会。  

##### 3b. 再看 `t_slow < q_slow`

**田忌最慢的马打不过齐王最慢的马。**  

**决策：用 `t_slow` 去消耗 `q_fast`，输掉这一场。**  

**为什么？** 此时 `t_fast == q_fast`，田忌最快的马只能和齐王最快的马打平，赢不了。而 `t_slow` 又打不过 `q_slow`，最慢的马也赢不了。那 `t_slow` 留着也没用，不如派它去消耗 `q_fast`（虽然输），保留 `t_fast` 和其他马，后面还有机会赢齐王的中等马。  

##### 3c. `t_slow == q_slow`

**双方最慢的马也相同。**  

**决策：用 `t_slow` 对 `q_fast`，结果取决于速度比较（通常是输或平）。**  

**为什么？** 此时双方最快的马相同、最慢的马也相同，田忌没有明显优势。派 `t_slow` 去对 `q_fast`，如果 `t_slow < q_fast` 就输一场，但保留了 `t_fast` 去赢齐王后面的马；如果恰好 `t_slow == q_fast`（所有马都一样快），那就是平局。  

整理一下就是：  

```cpp
1. t_fast > q_fast  →  t_fast 对 q_fast，赢
2. t_fast == q_fast →  进入细分：
     2a. t_slow > q_slow  →  t_slow 对 q_slow，赢
     2b. 否则              →  t_slow 对 q_fast，输（消耗）
3. t_fast < q_fast  →  直接 t_slow 对 q_fast，输（消耗）
```

对所有的n匹马都是这个决策，看当前双方最快和最慢的情况做出抉择
